# Security

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting channel for this repository. Do not open a public issue containing tokens, tenant identifiers, credentials, or other sensitive data. If private reporting is unavailable, contact the repository owner privately before disclosing details.

## Secret handling

Never commit credentials, signing keys, connection strings, or production configuration. Review generated artifacts and logs before publishing them. Use least-privilege identities and rotate any credential that may have been exposed.
