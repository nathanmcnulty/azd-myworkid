# Agent-assisted deployment

An agent may check prerequisites, initialize the template, explain configuration, run local validation, and summarize deployment evidence within the administrator's request.

Azure provisioning, Entra application changes, permission grants, Conditional Access, credential operations, custom-domain changes, and cleanup require explicit administrator authority. Before any authorized write, verify the signed-in account, tenant, subscription, target application IDs, package version, and reviewed settings.

Use normal cached operating-system broker or browser authentication. Never use device-code authentication or expose tokens, credentials, Verified ID secrets, TAP values, or real azd environment contents. Stop at an authentication, consent, tenant, permission, or DNS ownership blocker rather than working around it.
